# Documentation

  tests, install, versioning, checks and CI.
- [howto.md](howto.md): recipes for adding a library, a module, an app, tests, a dependency or an
  experiment.
- [new_repo.md](new_repo.md): creating a repo from `cmake_template` and keeping it in sync.
